Connect Google

This app talks directly to Google's Search Console and GA4 APIs from your browser — no backend, nothing stored server-side. You bring your own OAuth Client ID (free, takes ~3 minutes to create).

  1. Open Google Cloud Console → Credentials (create a project if you don't have one).
  2. Enable the Search Console API and Google Analytics Data API under "APIs & Services → Library".
  3. Create an OAuth Client ID of type "Web application".
  4. Under "Authorized JavaScript origins", add the URL this page is running on (e.g. ).
  5. Copy the generated Client ID and paste it below.
